                    PORTFOLIO ASSET & MEDIA SPECIFICATIONS
================================================================================

This document details every photo, video, aspect ratio, recommended resolution,
file path, and how to update video player credits for your portfolio.

All image and video assets are located inside the `public/assets/` directory.
When you replace a file with the same filename, it will automatically update across
the entire site.

3. VIDEOS / REELS PAGE & FULLSCREEN PLAYER (WITH CREDITS)
--------------------------------------------------------------------------------
The Videos page features a 3D WebGL barrel-distortion horizontal slider leading to
a fullscreen player with custom controls and a sliding Credits panel.

VIDEO FILES:
- File: public/assets/videos/video-1-cover.mp4 (or CDN URL)
  * Purpose: Video 1 short preview loop in the horizontal slider
  * Format: H.264 MP4 (Muted loop, 3-10 seconds)
  * Aspect Ratio: 16:9 (1920x1080 or 1280x720 px)

- File: public/assets/videos/video-1.mp4 (or CDN URL)
  * Purpose: Video 1 full video played in fullscreen player
  * Format: H.264 MP4 (With AAC audio)
  * Aspect Ratio: 16:9 (1920x1080 px)

- File: public/assets/videos/video-2-cover.mp4 (or CDN URL)
  * Purpose: Video 2 short preview loop

- File: public/assets/videos/video-2.mp4 (or CDN URL)
  * Purpose: Video 2 full video

HOW & WHERE TO UPDATE VIDEO CREDITS & METADATA:
File to edit: `src/pages/Videos.js` (lines 10 - 33)

You can customize the titles, durations, video URLs, and credits object:

```javascript
this.videosData = [
  {
    title: 'Show Highlight Reel',
    duration: '02:04',
    coverVideo: '/assets/videos/video-1-cover.mp4', // or your CDN URL
    fullVideo: '/assets/videos/video-1.mp4',        // or your CDN URL
    poster: '/assets/images/hero-1.jpg',
    credits: {
      director: 'Directed by John Doe',
      dop: 'Director of Photography: Jane Smith',
      editor: 'Edited by Alex Rivera',
      producedBy: 'Produced by Event Studio'
    }
  },
  {
    title: 'Corporate Gala Anchor',
    duration: '02:49',
    coverVideo: '/assets/videos/video-2-cover.mp4',
    fullVideo: '/assets/videos/video-2.mp4',
    poster: '/assets/images/hero-2.jpg',
    credits: {
      director: 'Directed by Michael Bay',
      dop: 'Director of Photography: Tyler Barks',
      host: 'Anchor: Shahid'
    }
  }
];
```

The fullscreen video player will dynamically populate the sliding "Credits" drawer
whenever the viewer clicks the "Credits" button on the bottom left.

GENERAL ASSET RECOMMENDATIONS:
--------------------------------------------------------------------------------
- Image File Format: JPEG (.jpg) with sRGB color profile, quality 85-92%
  (or WebP for faster delivery).
- Video File Format: MP4 (H.264 codec, AAC audio, web-optimized fast-start).
- File Naming: Keep exact filenames listed above so replacing them updates the site
  instantly without modifying any code.
